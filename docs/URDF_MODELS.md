# FL / LD 模型预览

从 Star Arm 102 控制台右上角点击「FL / LD 模型」，或打开同网站的 `urdf-preview.html`。模型资源均随网页提供，不依赖在线模型服务。

- FL · LumosTouch V3：用户提供的 FL URDF，六轴及两个平移夹指。夹指滑块单位为毫米，旋转关节为角度。
- LD · Touch R1：用户指定的 Touch R1 Leader Arm 描述，六轴、七个连杆、21 份结构/舵机/舵盘网格。保留各零件原有连杆归属。

拖动旋转模型，滚轮缩放，右键平移。「恢复 URDF 零位」恢复源文件定义的零姿态；「完整显示」让模型适应窗口。切换模型后姿态复位。模型加载失败会显示具体错误。

这是独立的模型姿态预览，页面不连接硬件。现有控制台的实机型号、串口协议和映射保留原配置。两份新模型的编码器零位、方向与机械安装关系需要逐轴确认后，才能用于实机数字孪生跟随；特别是 LD 上游尚未给出实机限位、编码器映射和动力学参数。滑块范围不代表实机安全运动范围。

源码资源位于 `Browser_SDK/assets/urdf/fl-v3/` 和 `ld-touch/`。`source.urdf` 为原文，`model.urdf` 为可移动目录的相对路径版本；使用时保留旁边的 `meshes/`。来源见根目录 `THIRD_PARTY.md`。
