# Star Arm 102 控制台 · 图文操作教程

控制台用于连接设备、查看三维姿态、主从控制、关节和末端目标操作，以及舵机设置。完整 ACT 流程另见 [ACT 图文教程](ACT_GUIDE.md)。本文截图均为实际网页的未连接状态。

## 1. 打开网页并认识界面

服务器方式直接访问提供方网站；源码方式按 [Ubuntu](UBUNTU.md) 或 [Windows](WINDOWS.md) 教程启动。推荐在桌面 Chrome / Edge 中使用。

![控制台界面](images/console-overview.png)

左侧是设备和控制入口，中间是三维视图，右侧是参数与目标。先完成设备连接，再使用对应的真实控制按钮。三维模型本身可在未连接设备时显示。

右上角“中文 / EN”切换控制台语言，新增的 LumosTouch 连接、校准和运行面板也随之切换。语言选择会保留到下次打开；切换语言保留当前设备连接、输入值和本次校准。

## 2. 分别连接主臂和从臂

![控制台设备面板](images/console-device-panel.png)

1. 将机械臂接到当前电脑，确认供电和 USB 线正常。
2. 在左侧选择实际使用的主臂类型。PiPER Mate 是支持的硬件类型之一；姿态来源的显示与可用控制以当前选择的硬件为准。
3. 点击主臂对应的连接按钮，在浏览器弹出的串口列表中选择主臂端口。
4. 选择从臂类型。使用真实机械臂时选择真实设备；虚拟从臂用于界面预览，不能驱动真实电机。
5. 点击从臂连接按钮，选择从臂端口。两台不同设备不能误选同一个端口。
6. 检查连接状态，并确认实际关节值能够更新。没有反馈时先处理设备连接，不要仅根据三维模型判断已连接。

浏览器串口选择必须由用户点击触发；服务器网站应使用 HTTPS。若没有设备列表，检查浏览器是否支持 Web Serial、系统权限和端口是否被其他软件占用。参见 [Chrome 官方串口说明](https://developer.chrome.com/docs/capabilities/serial)。

选择串口后，控制台会显示“串口已打开，正在读取 J1–J7”。新版每轮统一计时，只补读缺失关节；回包齐全立即完成，不会把等待时间乘以关节数量。调试设置里的响应超时按每轮计算，最多 3 轮；默认 800 ms 时，无回包的等待预算约 2.4 秒，另加系统打开串口和实际写入耗时。

首次连接必须取得当前连接的 J1–J7 有效角度。失败时会列出真实缺少的舵机 ID，并关闭此次串口；检查电源、串口和接线后可重新连接。连接日志分别记录“打开串口”和“首次回读”的实际耗时，便于区分系统驱动延迟与回包等待。已有连接中短暂丢包仍沿用该连接上次有效角度；不会把旧连接角度当作新连接成功。

## 3. 调整三维视角

使用鼠标拖动旋转、滚轮缩放，以及界面提供的默认视角、适应画面或全屏按钮查看机械臂。三维目标预览用于检查姿态；实际机械臂有没有跟随，需要结合真实反馈和现场观察。

页面隐藏或机械臂静止时会减少重复绘制；拖动、姿态变化和切换动画仍正常显示。浏览器缩放建议先恢复到 100%，小屏幕可收起浏览器侧栏或使用全屏。

## 4. 主从控制

1. 确认主臂和真实从臂均已连接，且两者数据正常。
2. 检查主从型号、关节对应和目标参数是否符合当前硬件。
3. 使用页面的主从控制启动按钮，先进行小范围操作并观察实际反馈。
4. 结束时使用停止按钮。切换页面也会先停止控制并释放串口。

控制参数需依据实际硬件与任务设置，不建议直接照搬其他型号的速度或关节范围。若主臂状态变化、从臂却不动，停止控制后检查从臂连接、关节映射和指令反馈。

## 5. 关节目标与末端目标

在对应控制面板中查看当前值、输入或拖动目标，先检查三维预览，再按页面按钮执行。关节目标与末端目标使用各自的控制入口；不要同时开启多个控制来源。

真实运动需要真实从臂连接及页面校验通过。虚拟模式中的姿态变化只是预览。执行后观察实际关节值与目标的差异；若没有跟随，停止并处理连接或驱动问题。

## 6. 轨迹管理

控制台轨迹功能仅用于 **Star Arm 102-FL**，可记录、编辑、预览和播放该型号的从臂轨迹。进入“轨迹记录”后，三维显示和设备连接固定为真实 FL；实时控制中选择的 LumosTouch 或虚拟型号不会带入。返回实时控制时恢复原来的型号和姿态来源选择，需要手动重新连接设备。导入或编辑后先检查轨迹与硬件匹配，再播放；结束时停止。

**控制台轨迹文件不是完整 ACT 数据集。** ACT 训练需要在 ACT 第 1 步记录同步的关节和双相机数据，并审核轮次；不能把只有关节目标的轨迹文件当成示教数据集。

## 7. 舵机设置与原点操作

![控制台舵机设置页](images/console-servo-setup.png)

舵机配置页提供 **Star Arm 102-LD** 三维模型，J1 至 J7 默认对应最终 ID 0 至 6。点击模型中的舵机、编号或下方记录可以选择单颗；拖动模型旋转，滚轮缩放。模型选择本身不会写入设备。

**自动逐颗配置**适用于七颗均为 **ID 0、115200 波特率**的出厂舵机。点击一次“连接并开始自动配置”，选好串口后，页面会等待新舵机并自动处理后续步骤。每次只新增一颗，已经配置好的保留在总线上；无需逐颗点击按钮。接线时的通断电按设备说明操作。

1. 接入 J1，页面读取到稳定的出厂参数后，自动写入临时 ID **253** 并回读核验。
2. 看到“等待接入 J2”再新增下一颗。页面依次将 J2 至 J7 自动设为 **1 至 6**。整个编号阶段保持 **115200**。
3. 七颗编号完成后，页面自动将第一颗从 **253 恢复为 0**。
4. 接着自动将七颗依次改为 **1000000**，逐颗回读，最后在新速率下再次核验全部七颗。恢复 ID 和统一速率都不需要再次点击。

“暂停自动配置”会等待当前核验结束后暂停；等待新舵机时也可暂停。暂停后新增舵机不会触发写入，点击继续后才会恢复。离开页面会停止自动流程并释放串口，重新进入需手动启动。

目标 ID 在 115200 或 1000000 下已被占用、已配置舵机丢失或参数核验失败时，自动流程会停止并显示原因。回读超时不代表写入一定失败；保留当前总线，点击“核验并继续自动配置”。页面先只读检查原 ID、目标 ID 和两种速率，确认上次写入生效才继续；若未生效则暂停，不会自动重写。当前标签页保存配置进度，重新连接后会读取实际参数；导出的配置记录用于核对，不会自动恢复硬件。

模型中第五颗是上方腕部舵机，第六颗是横向腕部舵机，第七颗是夹爪舵机。编号跟随机壳中心，点选后仅高亮对应机壳；支架和握柄不作为这三颗舵机的点选实体。

**单颗修改**保留原来的读取、修改与确认功能。选中模型中的目标舵机，填写它的当前 ID 和波特率并读取，再输入目标 ID（0 至 253）及波特率（115200 或 1000000），核对确认窗口后写入并回读。总线上这颗舵机的当前 ID 必须唯一。进行中的逐颗向导需先完成，或新建页面记录后再使用单颗修改；新建记录不会还原已写入的设备参数。

原点重置、工厂恢复和 ACT 从臂范围校准用途不同。正常采集或训练不要求每次重新设置舵机 ID、恢复工厂参数或重置原点。只有设备配置确实需要维护时才使用这些入口。

## 8. 去 ACT 或返回控制台

点击 ACT 入口后会先结束当前控制并释放串口，显示约 5 秒全屏切换画面。ACT 顶部的 **控制台** 按钮可返回。

返回后的设备需要在目标页面重新连接。页面切换提示设备释放失败时，先处理提示；若仍有未保存的校准或待审核记录，先按页面要求完成。
