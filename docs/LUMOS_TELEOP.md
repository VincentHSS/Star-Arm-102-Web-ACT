# Lumos Ubuntu 本地控制

本教程对应 `Star-Arm-102-Lumos-Ubuntu-v1.0.38.zip`，用于 Touch R1 主臂 → LumosTouch V3 从臂的六轴与夹爪遥操作。

## 1. 下载与启动

要求 Ubuntu 22.04 / 24.04 x86-64、系统 Python 3.10～3.12、桌面 Chrome / Edge。首次需要联网准备系统依赖和固定版本 SDK；后续复用已准备的环境。

从 [最新发布](https://github.com/VincentHSS/Star-Arm-102-Web-ACT/releases/latest) 下载 Lumos ZIP，完整解压，在解压目录打开终端：

```bash
bash start_ubuntu_lumos.sh
```

如果使用 Code → Download ZIP 的整个仓库源码：

```bash
cd delivery/Star-Arm-102-Lumos-Ubuntu-v1.0.38
bash start_ubuntu_lumos.sh
```

以普通桌面用户启动；系统依赖安装时单独按提示授权。启动器使用系统 Python，终端显示 `(base)` 不影响这一入口。保持终端开启，首次下载和编译可能需要数分钟。

准备完成后自动打开终端显示的地址。默认优先使用 `http://127.0.0.1:18767/index.html`，占用时自动选择其他空闲端口。也可指定：

```bash
bash start_ubuntu_lumos.sh --port 18800
```

`--no-browser` 只启动服务；`--state-dir /实际路径/lumos-data` 指定数据目录。重复启动只复用源码、版本和数据目录一致的实例，不会结束其他服务。

## 2. 配置 CAN

先停止控制并断开设备，在包目录另开终端查看接口：

```bash
ip -details link show type can
```

若实际接口为 `can0`，运行包内脚本：

```bash
sudo bash configure_can.sh can0
```

输出应包含 `UP` 和 `bitrate 1000000`，即 1 Mbps。接口是 `can1` 时，命令与页面中的 CAN 接口都使用 `can1`。如果查询无输出，先确认 USB-CAN 设备及驱动是否识别。

Touch R1 串口波特率在页面“连接设置”中按主臂实际配置选择 1000000 或 921600；它与 CAN 1 Mbps 分开设置。

## 3. 连接设备

页面分为左侧连接与校准、中间三维姿态、右侧关节反馈。

1. 点击“连接 Touch R1”，在浏览器授权窗口选择主臂串口。
2. 填写实际 CAN 接口，点击“检查连接”，核对返回的夹爪型号。
3. 确认设备与工作区域安全，勾选使能确认，再连接 LumosTouch。连接会使能电机。

Touch R1 使用浏览器 Web Serial，从臂通过本机 SDK 和 CAN 运行。同一台设备同时只使用一个控制程序。实体按钮板为可选项，在连接前于“连接设置”中配置。

## 4. 首次校准

1. 将两臂和夹爪放到对应参考姿态，展开“关节映射与方向”核对映射、方向、增益及夹爪反向。
2. 点击“记录参考姿态”，缓慢逐轴移动主臂采集范围，每轴至少覆盖 2°。
3. 将主臂夹爪放到闭合端点，点击“记录闭合”；再放到张开端点，点击“记录张开”。保持姿态直至页面确认。
4. 两个夹爪端点原始读数需相差至少 2°，随后点击“完成校准，查看预览”。
5. 核对六轴方向与目标预览，对齐主从夹爪开度，确认后手动开始。

采集校准期间从臂不跟随主臂。预览不是运动命令，开始跟随需要明确确认。主臂 ID 0～5 六轴和 ID 6 夹爪必须完整回读。

## 5. 复用上次校准

重新连接后，如存在兼容的已保存校准，页面会显示“复用上次校准”。

1. 确认仍使用同一套设备，安装、机械零位、夹爪型号和接线未变化。
2. 将两臂及夹爪放回上次参考姿态，勾选复用确认并执行检查。
3. 检查通过后仍需核对预览，并手动确认开始；程序不会自动恢复运动。

设备、零位、夹爪或安装条件有变化时重新校准。停止或超时后需要重新连接，再由当前反馈决定是否能复用。

## 6. 停止、退出与数据

结束时先在页面停止并断开设备，再回启动终端按 Ctrl+C。紧急情况使用页面紧急停止及现场硬件急停。

- 校准数据：`~/.local/share/star-arm-102/lumos/data`。
- SDK 与独立 Python 环境：`~/.cache/star-arm-102/lumos/`。
- 设置了 XDG 路径时，以对应环境路径为准；错误信息显示在启动终端和页面状态中。

升级文档或界面无需删除已有环境和校准目录。先正常退出旧版，再启动新版。

## 常见问题

| 提示 | 处理 |
| --- | --- |
| `--port` 不被识别、报错仍指向 18766 | 检查当前目录；进入本教程对应的 `delivery/Star-Arm-102-Lumos-Ubuntu-v1.0.38/`，不要运行仓库根目录旧入口 |
| 指定端口被占用 | 不指定端口以自动选择，或使用其他空闲 `--port` |
| CAN 未启用或不是 1 Mbps | 按第 2 节配置实际接口，页面使用同名接口 |
| 串口权限不足 | 核对当前用户的 `dialout` 组权限；管理员添加权限后需重新登录桌面 |
| `feedback_valid=False`、年龄为 `inf` | SDK 当前没有有效夹爪反馈；记录完整页面错误和启动日志，核对当前 SDK 环境、运行程序和型号配置，不能仅凭这一提示判定硬件损坏 |
| 下载或依赖安装失败 | 保留具体错误，网络或系统软件管理器恢复后重启同一入口，已准备的环境可复用 |

网站下载的 `.deb` 是原网站连接组件，使用 `sudo apt install ./实际文件名.deb` 安装。Lumos 专用本地 ZIP 使用 Bash 启动，不需要先运行 `.deb`。
