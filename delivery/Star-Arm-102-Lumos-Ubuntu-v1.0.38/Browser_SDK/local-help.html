Lumos 使用说明

启动

bash start_ubuntu_lumos.sh

首次需要联网准备依赖；请等待终端显示控制台地址。适用 Ubuntu 22.04 / 24.04 x86-64、Python 3.10～3.12、Chrome / Edge。

CAN 配置

停止控制并断开设备后，将实际 CAN 接口配置为 1 Mbps：

sudo bash configure_can.sh can0

接口名须与页面一致。Touch R1 波特率在“连接设置”中单独选择。

操作

  1. 连接 Touch R1，检查 LumosTouch 和夹爪型号。
  2. 确认设备与工作区域安全，连接 LumosTouch。
  3. 完成参考姿态、六轴范围和夹爪端点校准，或检查并复用已有校准。
  4. 核对方向和预览，手动确认开始。
  5. 结束时先停止、断开设备，再在终端按 Ctrl+C。

同一台设备同时只使用一个控制程序。紧急情况使用页面停止按钮及现场硬件急停。
