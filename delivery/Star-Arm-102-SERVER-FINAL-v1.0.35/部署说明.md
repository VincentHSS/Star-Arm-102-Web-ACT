# Star Arm 102 · 服务器提速版 v1.0.35


## v1.0.35：模型加载提速

此前为兼容慢速网络，模型总是拆成 64 KiB 小请求，并跳过浏览器缓存。LumosTouch V3 的 9 个压缩部件因此需要 125 次请求；原站整机加载会比单个部件测试慢。本版优先连续读取完整文件，出错后再转为小段续传，并保存通过完整性校验的模型数据。

- 正常连接下每个部件只发起一次请求，Lumos 首次正常读取为 9 次资源请求。
- 保留 60 秒连续无数据超时、部分响应续传、失败后减小分段、原始 STL 回退和 SHA256 校验。
- 已通过校验的压缩模型保存在内存及浏览器 Cache Storage。再次切换、刷新或重开时优先验证并复用缓存；缓存命中时无需下载该模型资源。浏览器禁止缓存或空间不足时，正常回到网络读取。
- 模型使用带内容哈希的资源地址。模型文件更新会使用新键；发现缓存损坏会删除该项并重新读取。
- 独立部件最多同时加载 4 个；重复同步同一个正在加载的模型共用一次请求，并去掉控制台启动时多余的默认模型加载。
- 本次仅更新模型显示与资源加载流程。原始模型、压缩文件、控制映射及 Ubuntu 组件继续使用原版本。

### 小更新包

若服务器已部署前面交付的 v1.0.33 或 v1.0.34，可使用提速更新包。将“服务器网页”内全部文件完整覆盖到原 Browser_SDK 目录，清理该路径 HTML / JS 的 CDN 缓存，再按 Ctrl+Shift+R。

确认控制台显示 `v1.1.2 · srv1.0.35`。更新包不包含大型模型文件，使用原站已有 assets/mesh-data/、原始 STL 和 vendor 文件；更旧或文件不完整的网站请使用完整 v1.0.35 包。

首次仍需下载并校验模型数据；再次加载命中缓存后跳过模型下载。首次实际耗时仍取决于服务器带宽、网络与电脑性能。无需为本次模型加载提速重新安装已正常工作的客户端组件。

安装组件后首次准备 SDK 和系统依赖仍需联网。本包不是包含所有运行依赖的完全离线环境；组件运行版本保持 Lumos 1.0.32 / ACT 1.0.23，仅重新生成本站绑定安装文件。

## 上传方法

**只把“服务器网页”目录里面的全部文件上传到网站目录，启用 HTTPS。**

解压后包含服务器网页、Ubuntu安装包、部署说明、修复说明、验证记录和 SHA256SUMS。网站根目录应直接包含 index.html、act-workbench.html、act-browser.html、urdf-preview.html、src/、assets/ 和 downloads/。不要把本地验证包的 start_ubuntu.sh 或 app/ 上传到网站。

可使用宝塔面板、SFTP、Nginx、Apache 或支持这些资源的静态托管。服务器无需安装 Python、Lumos SDK、机械臂驱动或连接机械臂；设备连接在客户电脑进行。

1. 备份现有网站，在单独目录上传完整“服务器网页”内容，确认后切换网站目录。
2. 保持所有子目录结构，模型、JS、WASM 和两个 .deb 模板均需保留。
3. 启用有效 HTTPS 证书，用桌面 Chrome / Edge 打开网站。远程 HTTP 地址无法正常使用串口等浏览器功能。
4. 清理 CDN / 网站旧缓存，浏览器强制刷新。HTML 与未变文件名的 JS 建议使用 Cache-Control: no-cache；不要只替换 index.html。
5. JS 返回 JavaScript MIME，WASM 返回 application/wasm；缺失文件返回 404，不能回退成首页 HTML。安装模板须原样提供，禁用内容改写。

网站可位于域名根目录或子目录，保持相对目录结构即可；网页会读取当前网站地址，不需要在源码填写域名。

## 上传后检查

假设网站为 https://你的域名/，下列地址应能打开或下载（子目录部署时加对应前缀）：

- index.html：控制台及三维模型正常显示。
- act-workbench.html：ACT 工作台正常打开。
- src/app.js：返回 JS 源码，不是首页 HTML。
- downloads/lumos-runtime-template.deb：Lumos 安装模板可下载。
- downloads/act-runtime-template.deb：ACT 安装模板可下载。

公开模板尚未绑定网站，客户应在网页点击下载按钮生成专属安装包；不要直接把 downloads 里的模板发给客户安装。网页会校验模板 SHA256，并绑定下载时的网站协议、域名和端口。

如果现有网站配置了 CSP，需允许同源脚本、模型及模板读取，并允许连接 http://127.0.0.1:18766；保留 ACT 功能时也允许 http://127.0.0.1:18765 的连接与媒体请求。现有 Permissions-Policy 不应禁止 serial 或 camera 等已使用的功能。客户电脑上的本机地址不能替换成服务器地址，也不需要在服务器开放 18765 / 18766。

## Ubuntu 客户首次使用

适用 Ubuntu 22.04 / 24.04 桌面版、Intel / AMD x86-64、新版 Chrome / Edge。

1. 打开你的 HTTPS 网站，选择 Touch R1 主臂和真实 LumosTouch 从臂，点击“安装 Ubuntu 连接组件”。
2. 在下载目录双击生成的 star-arm-lumos_1.0.32_amd64.deb，使用系统软件安装器安装并完成管理员授权；下载完成不等于安装完成。
3. 回到原网页，允许浏览器提示的本机网络访问，等待连接组件准备完成。未检测到时，从 Ubuntu 应用菜单打开“Lumos 机械臂连接助手”，再点击“检查组件”。
4. 插入设备，选择正确的 USB-CAN，点击“配置 CAN · 系统授权”并完成系统授权。CAN 为 **1 Mbps**；Touch R1 串口按电机实际配置选择 **921600 或 1000000**，两者独立。
5. 按网页授权主臂串口，核对夹爪型号与使能确认，连接从臂；首次校准，检查预览后再开始。设备、安装和零位未变时可按网页检查并复用上次校准。

首次安装需要联网访问 Ubuntu 软件源、GitHub SDK 下载地址及 Python 包源；此服务器包不是离线客户端安装包。网络准备失败时查看页面具体错误并重试。组件日志：~/.local/share/star-arm-102/lumos/companion/runtime.log。

## 原有功能与组件版本

本版保留所有页面和现有功能，包括 ACT、舵机配置、实体按钮板、校准保存复用、可调频率及滤波。虚拟 Lumos **仅反转 J6 跟随方向，J5 保持原方向**；实体 Lumos 映射不变。

完整更新网页及两个模板；客户本机组件不会因服务器文件更新而自动升级。新客户通过网页安装 1.0.32；已安装最新本地验证包 1.0.32 的客户，在同一网站绑定有效时无需为这次前端方向修改重新安装组件。旧组件或切换网站地址时，需安装从目标网站生成的新版组件。升级前先停止遥操作并断开设备；不要在执行过程中安装或切换。

网站协议、域名或端口变化时需重新绑定；仅改变域名下的路径不会改变 origin。首次从本地验证地址切到服务器网站，也需要使用服务器网站生成的安装包完成绑定。
