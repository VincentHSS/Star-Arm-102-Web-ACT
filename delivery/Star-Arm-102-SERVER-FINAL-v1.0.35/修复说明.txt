Star Arm 102 模型加载提速 v1.0.35

适用：服务器已部署前面交付的 v1.0.33 / v1.0.34，且模型文件已能正常显示。

安装：
1. 备份原 Browser_SDK 目录。
2. 将本包“服务器网页”目录中的所有文件完整覆盖到原网站对应目录，保持目录层级。
3. 清理该路径 HTML / JS 的 CDN 缓存，浏览器按 Ctrl+Shift+R。
4. 页面应显示 v1.1.2 · srv1.0.35。
5. 首次完成模型加载后，再普通刷新一次，检查缓存加载效果。

此更新包使用原站已有的 assets/mesh-data/、原始 STL 和 vendor 文件，无需重传大型模型，也无需为加载提速重新安装已正常工作的 Ubuntu 组件。
若网站版本更旧或文件不全，使用完整 Star-Arm-102-SERVER-FINAL-v1.0.35.zip。

修改：
正常时连续下载完整压缩文件，遇到异常才用小段继续读取；保留慢网超时与续传处理。Lumos 的正常首次请求从 125 次减到 9 次。
缓存通过完整性校验的模型。命中缓存后无需再次下载；缓存不可用时仍可正常加载。
独立模型部件最多同时读取 4 个，合并重复加载请求，去掉首屏多余的默认模型加载。

本地验证：20 项回归检查通过，覆盖全部 91 份模型的 HTTP 读取和解析。模型文件和 Ubuntu 组件未改动。正式服务器和 Ubuntu 实机性能待上传后确认。
